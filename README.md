# Mossrune

A small 2D top-down arcade action game with RPG elements, set in overgrown ruins.
Survive waves of enemies, collect XP, level up and choose upgrades.

Built with [Godot 4.7](https://godotengine.org).

Documentation lives in the [wiki](https://github.com/Voltair88/mossrune/wiki).

## Quick start

1. Install Godot 4.7.2 (`winget install -e --id GodotEngine.GodotEngine`).
2. Open this folder in Godot and press F5, or run `godot --path .` from here.

## Controls

| Action | Keys |
|---|---|
| Move | WASD / arrow keys |
| Attack | Space / J |
